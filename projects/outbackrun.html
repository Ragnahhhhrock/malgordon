Outback Run

2026 — Present · Founder

An Out Run-style arcade racer across the Nullarbor Plain — Perth to the East Coast, 5 legs, 15 stages, 5 endings. Built with Kimi3.

Visit Outback Run →

Outcomes

  • Shipped a full arcade racer in the browser, styled after the classic Out Run formula — fork-in-the-road route choices, gear shifting, and a soundtrack toggle.
  • Structured the run as 5 legs across 15 stages, with 5 different endings depending on the route taken.
  • Built dual control schemes: keyboard (arrow keys/WASD plus shift-to-change-gear) for desktop, and a touch steering wheel with thumb-operated gas/brake for mobile.
  • Added a local hi-score table with initials entry, keeping the classic arcade-cabinet feel.
  • Built with Kimi3 as an AI coding collaborator.
